# v3.36.1 — 子代理委派全灭热修与工具调用协议加固

> 日期：2026-10-23
> 上一版本：v3.36.0

## 本版说明

本版是一次**热修发布**。v3.35.0 与 v3.36.0 中，所有子代理调用（`delegate_task` / `delegate_batch` / `galaxy`）必然失败，报错 `[static-subagent] top-level parse is lossy: parsed 13 sections covering 16834 of 16833 chars`，重启无效。

根因：3.35.0 周期的一笔交付修复在编辑 `<shared-worktree>` 规则段时带走了两处段间空行（`\n\n` → `\n`），而子代理提示词裁剪器写死按 `\n\n` 重组并做逐字节无损断言——断言 fail-closed 抛错，每个 worker 派生都要过它，于是委派链路全灭。缺陷打包在运行时产物里，只能随新版本修复。

## 内容清单

- **子代理解析器修复（主打）**：
  - `parsePrompt` 改为按原文记录每个段的真实分隔符（`separatorBefore`），不再假设统一 `\n\n`；新增「单换行顶层边界」回归用例，断言失败即红的金哈希守卫同步对齐。
  - 影响面核实：v3.35.0 / v3.36.0 两个版本的全部委派入口 100% 失败；主会话对话不受影响。

- **工具调用协议加固（同族事故链修复）**：
  - 主控提示词只点名本次实际提供的工具——此前默认 minimal 档没有 apply_patch 等 EXTENDED 工具，提示词却仍命令模型「改用 apply_patch」，模型照做即触发未声明工具名错误（`ToolNameProtocolError(unknown)`），整次响应作废。行级门控与子代理裁剪共用同一份门控表；工具目录齐全的会话提示词逐字节不变，前缀缓存不受影响。
  - 兼容部分 OpenAI 兼容网关的 `functions.<工具名>` 命名空间包装，归一到已声明工具名；未声明的 `functions.*` 仍按 unknown 拒绝。
  - `ToolNameProtocolError` 从通用 client_error 拆出为独立的 `tool_protocol` 错误类：文案明示「本次工具未执行」，恢复指引按 TUI / 桌面端分流（桌面端不再被指向不存在的斜杠命令）。

- **续跑与锁稳定**：
  - 续跑 rebase 收严：缺 `wireTransformVersion` 的 legacy 证明不再允许静默替换 transport 基线，须走显式修复事务（issue #500 不变量）。
  - 睡眠唤醒 / 主机名变更后的 stale 锁属主恢复，消除僵尸误判与丢锁误判。
  - 交付候选证据跨重试保持稳定。

- **TUI**：收编公开仓 PR #531 会话命令工作流（/goal 等会话命令族，感谢社区贡献）。

- **trace-lab 插件**：星域解读实验插件——确定性工具（cases / run / compare / export）+ 桌面端 HTML 工件卡通路；插件路径安全包装同步纳入 `data_dir` / `annotation_path` 参数。

- **构建修复**：Linux 容器构建锁目录父级先自建（干净检出不再直接失败）；源码拷贝 tar 排除 xattr 与根 `node_modules`。

## 升级注意

- 从 v3.36.0 直接自动更新即可，无需迁移。
- 3.35.0 / 3.36.0 的委派失败为运行时缺陷，升级后立即恢复，无需任何配置变更；升级前因该缺陷中断的会话可正常续用。

## 已知限制

- 本版不含 Node 运行时变更，安全闸门要求与 v3.36.0 相同（Node 24.x ≥ 24.22.1 或 26.x ≥ 26.12.1）。
