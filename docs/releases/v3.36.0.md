# v3.36.0 — Node 安全运行时闸门与 2026-10 安全公告修复

> 日期：2026-10-22
> 上一版本：v3.35.0

## 本版说明

本版是一次**安全驱动**的发布。Node.js 于 2026-10-21 发布安全更新，修复 10 个漏洞（含 4 个高危），修复版本为 24.22.1 / 26.12.1。天枢作为客户端，其中 Brotli 解码器越界写入（CVE-2026-111497）对我们是真实可达的远程攻击面：所有 HTTP 响应经 fetch 自动解压，web_fetch 抓取的任意 URL、用户配置的 API 端点、MCP 服务器与代理都可能投递恶意压缩流。

因此本版不仅升级了运行时 pin，还新增了**启动时的运行时安全闸门**：CLI 与桌面 sidecar 在版本低于安全线时直接拒绝启动，而不是带着已知漏洞继续跑。

## 内容清单

- **运行时安全闸门（主打）**：
  - 新增 `src/platform/node-security-policy.ts`：只接受 Node 24.x ≥ 24.22.1 与 26.x ≥ 26.12.1；其余版本（包括已修复但不在支持线的 22.23.4）一律拒绝，错误消息给出明确升级指引。
  - CLI 两个入口（`src/cli/entry.ts`、`src/main.ts`）在路由任何命令前执行检查；`--version`/`--help` 的快速路径保持可用（不加载重模块，无攻击面）。
  - 桌面端：bundled runtime 版本在下载前校验；打包版缺失 bundled Node 时不再回退系统 Node（Rust `select_node_cmd`），避免静默使用带漏洞的系统运行时。
  - `scripts/install-tui.sh` / `install-tui.ps1` 安装前检查版本；`desktop/scripts/fetch-node-runtime.sh` 改为委托 JS 实现，单一版本策略。

- **Node pin 升级到 24.22.1**：
  - 覆盖 `.nvmrc`、`.node-version`、CLI 与桌面端 runtime fetcher、Linux 容器构建、Windows 打包闸门、桌面 `engines`。
  - 修复公告覆盖的 10 个漏洞，其中与本项目相关的高危项：Brotli 解码器越界写入（远程可达 RCE）、`dns.resolve` NUL 域名截断、TLS 主机名校验绕过（全角数字 IP / 宽松解析）。
  - ABI 不变（`NODE_MODULE_VERSION` 仍为 137），`better-sqlite3` 无需重编；实测下载并通过 SHASUMS256 校验。
  - `engines` 收紧为 `^24.22.1 || ^26.12.1`。

- **回归测试与文档**：
  - 新增安全策略单测（版本矩阵、入口接线、安装脚本、CLI 子进程拒绝、桌面 fetcher 拒绝）。
  - 补上 `fetch-node-runtime` 的缓存 marker 回归测试：旧版本 marker 存在时必须重新下载，而不是复用旧运行时。
  - Mac 打包手册、provider-usage 构建说明同步到 24.22.1；发版流程按 v3.35.0 实跑定版清理。

## 升级注意

- **本版起，Node 低于 24.22.1（或 26.x 低于 26.12.1）将无法启动 CLI 与桌面 sidecar。** 升级前请先切换运行时：`nvm use` / `fnm use`（仓库 `.nvmrc` 已指向 24.22.1），或安装 Node 24.22.1+。
- Node 22.x 不在支持范围（`engines` 要求 24/26 线），即使 22.23.4 已含本次修复也会被拒绝。
- 桌面端自带的 runtime 会随安装包升级到 24.22.1，无需用户单独安装 Node；CLI 用户需要自备符合要求的运行时。

## 已知限制

- 安全闸门只在进程启动时检查，运行中热切换 Node 不在覆盖范围。
- `--version` / `--help` 不触发闸门（设计如此，仅输出静态文本）。
