## 1. Token 消耗台账与论坛同步

- **本地台账与折叠引擎**（`2370809bc`）：`src/token-ledger/` 落地——字节游标增量折叠 cache-log 计费行（主请求 + side_path + 中断重试，与 usage-aggregator 同口径），按 day×model 累计到 `~/.rivet/token-ledger.json`；跨进程 StoreLock（5s 预算，超时保数据拒绝提交）；安装级 deviceId 身份文件，损坏账本沿用原设备 ID 恢复，无法恢复时拒绝重建避免重复累计
- **token-server 三段式中间层**（`a8f69d3b8` + `55c432cc0` + `d4fa8efb6` + `7b369457d`）：Cloudflare Worker + D1 附属服务——`POST /v1/token-usage` 累计语义 upsert（重推/乱序/丢包不重复计数）、stale 守卫（不前进的整包丢弃）、admin 签发/吊销密钥（明文只返回一次，库存 sha256）、admin 读单用户用量接口（论坛个人页不再需要持有明文密钥）、设备归属守卫（跨成员改绑 409，旧包整批回滚）
- **CLI 与 VS Code 接入**（收编 PR #448，`492b72402`）：`/usage` 查看全设备本地累计、`/usage connect` 遮蔽输入框配置密钥、`/usage sync` 立即同步、`/usage auto on|off` 显式开关每 30 分钟上传；VS Code 设置抽屉同构。密钥只接受用户配置，仓库项目配置不能自行启用或改变上传目标
- **桌面端全量接入**（`0668d5cc1` + `9f6194169` + PR #18 `528329dbb`）：设置新增「Token 账本」页（本设备累计/缓存命中率/计价数值/逐日明细）；Composer、欢迎页与新建会话对话框接入 `/usage` 命令（回车直达面板）；同步密钥防泄漏多点拦截——账本命令开头的输入不进草稿持久化（加载时回写清理历史残留），命令面不接受密钥参数，上游错误文本不透传进 UI；上游 401/409 回执映射为「密钥无效/设备已绑定」明确文案
- **退出与生命周期加固**（`9f6194169`）：shutdown 冲刷改为本地保存与在途手动同步并行有界等待（3s）；配置热更新（reconfigure）中止在途同步并重建定时器；`forum.apiKeySource` 三态（environment/saved/none）让「环境变量密钥仍生效」在 UI 明示
- **接入交接文档**（`d9eb87a89`）：`docs/reference/token-ledger-forum-sync.md` 完整契约（客户端→token-server→论坛三段式、字段表、响应语义、本地调试通道）

## 3. 桌面端会话流稳定（#363/#373 系列）

- **滚动恢复稳定化**（`da3141b8a` + `601108658`，#363）：切回会话不再丢失阅读位置——基于表面返回探针的完整取证（baseline 录制 + 双引擎对照）后重写恢复判据

- **整轮折叠恢复**（`620ce30d6`）：带折叠推理的整轮折叠回归修复，中间轮叙述保持折叠进时间线（QA 套件 + 三引擎截图证据）
- **审批与提问卡重设计**（`b67657501`）：紧凑卡重排，主操作更可达；配套 verify-decision-cards 验收脚本

## 4. 引擎与内核

- **执行连续性钉扎**（`b048444ff`）：主会话、隔离 worker 与显式续跑的最终请求钉扎模型、凭据、推理选项、工具集与历史前缀——未批准的前缀变更与不可用的固定绑定就地拦截，不再静默漂移
- **终态 worker 停止语义**（同上）：传输重试/模型回退/报告修复/预算续跑/隔离补偿全部不再应用于终态失败的 worker——失败就是失败，不再僵尸续命
- **模型路由跟随主会话**（`f5bc29906`）：路由决策显式暴露并跟随主会话，worker 不再误接主会话模型切换
- **Anthropic 最终流缓存用量接受**（`2fce33735`）：终块 usage 不再丢弃
- **跨会话文件认领原子化**（`77c5afd55`）：claim 写入原子化，并发会话不再互相覆盖认领
- **Git 新鲜度探针 drain**（`92ff95c61`）：run 收尾前排空探针，不再泄漏到下一会话
- **流式动作稳定与增长追赶消费者**（PR #17 `7795ab580`）：流式动作分派稳定化 + 事件增长追赶消费者验证
