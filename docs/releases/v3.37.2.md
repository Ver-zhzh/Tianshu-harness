# v3.37.2 — 桌面无代理更新直连修复

> 日期：2026-10-30
> 上一版本：v3.37.1

## 本版说明

本版是一次**桌面更新器补丁发布**，修复未配置代理时无法下载更新的问题。v3.37.1 的会话收尾、observer 与其他功能行为不变。

## 内容清单

- **无代理更新恢复直连**：未配置代理时，AtomGit、GitHub 与手动 OSS 下载不再误走代理路由，避免在接收 0 字节时以 `proxy_configuration` 失败。
- **代理回退保持不变**：配置代理后仍按代理优先、直连兜底执行。
- **回归覆盖**：新增无代理路由与真实本地 HTTP 下载测试，并验证代理回退、下载超时和续传行为不受影响。

## 升级注意

- **v3.37.0 / v3.37.1 桌面客户端需手动下载 3.37.2 的 DMG 或 setup 覆盖安装一次**。旧客户端自身的更新器包含此缺陷，无法通过应用内重试完成本次升级；覆盖安装不影响既有会话与配置，安装 3.37.2 后可恢复正常自动更新。
- 从 3.37.2 升级无需迁移。
- macOS 包仍未公证；如首次打开被 Gatekeeper 拦截，安装后执行 `xattr -cr /Applications/Tianshu.app`。
