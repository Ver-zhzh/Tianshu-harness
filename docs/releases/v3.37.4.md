# v3.37.4 — Windows 覆盖安装隔离修复

> 日期：2026-10-31
> 上一版本：v3.37.3

## 本版说明

本版是一次 **Windows 安装器热修复**，处理 v3.37.3 覆盖安装时旧运行时目录清理失败、安装被阻断的问题。其他功能行为与 v3.37.3 保持一致。

## 内容清单

- **旧运行时不再直接删除**：覆盖安装前，`node-runtime`、`rivet-runtime` 和 `mobile-web` 改为移入安装卷内的唯一隔离目录，不再以 `RMDir /r` 成功作为安装前提。
- **失败诊断更准确**：只有隔离改名本身失败才中止安装，日志记录具体源路径与目标路径，不再用笼统的“文件被占用”掩盖真实清理错误。
- **数据保留与回滚**：旧运行时保留在隔离目录中，便于升级失败时恢复；`TianshuData`、账号、Provider 配置和会话数据不参与隔离。

## 升级注意

- 从 v3.37.3 升级无需迁移，既有会话与配置保持不变。
- Windows 安装包仍不附带 Authenticode；自动更新所需的 `.sig` 正常生成并校验。
- macOS 包仍未公证；如首次打开被 Gatekeeper 拦截，安装后执行 `xattr -cr /Applications/Tianshu.app`。
