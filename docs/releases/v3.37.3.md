# v3.37.3 — 会话恢复、桌面稳定性与网络修复

> 日期：2026-10-30
> 上一版本：v3.37.2

## 本版说明

本版是一次**稳定性补丁发布**，重点加强会话持久化与崩溃恢复，修复桌面启动和阅读滚动问题，并统一代理绕过与更新下载路由。MiniMax 预设同步升级到 M3.1 Flash。

## 内容清单

- **会话持久化与崩溃恢复**：会话历史改为执行前持久化，补齐崩溃后的历史抢救入口；恢复会话时保留原有上下文前缀，并在压缩前修复仍有效的历史记录，降低异常中断后上下文损坏或无法续聊的风险。
- **桌面启动安全模式**：新增反复启动崩溃后的安全模式与恢复提示，为连续启动失败提供可进入的恢复路径。
- **阅读滚动与工作组显示**：修复阅读锚点撤销用户滚动的问题；折叠工作组的虚拟列表高度估值与实际显示保持一致，减少会话流跳动和错位。
- **代理与更新路由**：桌面端和各模型协议统一继承代理及 `NO_PROXY`；绕过规则支持通配、域名、端口和 IPv4 网段，配置与环境变量叠加生效。更新下载按 URL 选择代理或直连，修复默认端口绕过失效及无代理时重复直连的问题。
- **MiniMax M3.1 Flash**：默认模型升级为 MiniMax-M3.1-Flash，声明 1M 上下文及图片、视频输入能力；全球端点与国内配置示例分别对齐。

## 升级注意

- 从 v3.37.2 升级无需迁移，既有会话与配置保持不变。
- **v3.37.0 / v3.37.1 桌面客户端仍需手动下载 DMG 或 setup 覆盖安装一次**。旧客户端自身的更新器缺陷无法通过应用内重试完成升级；覆盖安装不影响既有会话与配置。
- macOS 包仍未公证；如首次打开被 Gatekeeper 拦截，安装后执行 `xattr -cr /Applications/Tianshu.app`。
