# v3.34.0 — 安全加固与执行可靠性

> 日期：2026-10-19
> 上一版本：v3.33.1（稳定通道）

## 本版说明

本版主轴是**安全加固与执行可靠性**：收编社区 PR 三批（#494/#503/#509/#511），修复生图与探测端点的网络访问策略（issue #456，SSRF 面），并系统性修正工具执行反馈——环境类失败不再被误导性地归因为「环境问题，重试即可」，退出码与测试证据的判读回到正确口径。另含 GLM pro 账户额度查询修复（issue #516）与 Mimo 模型切换。

## 内容清单

- **安全（重要）**：
  - **生图与探测端点的网络访问策略**（issue #456）：默认只访问公网；本机与局域网端点须用户显式授权，且许可绑定到具体 origin——DNS 失败不自动放行，端点请求与响应中图片下载使用不同权限。此前生图首跳经原始 fetch 发 POST，不受既有下载守卫保护。
  - **多 key 池凭据守卫收紧**（PR #503 收编）：修复守卫在路由场景恒短路——loadConfig 深合并把 deepseek 预设自带的 `apiKeyEnv` 注入池化 provider 顶层，预设环境变量名可击穿显式 key 配置；补全劫持回归测试。
  - **clean 强制参数判据统一**（PR #494 收编）：approval、执行与 advisory 三道门共用同一 clean option 边界检测，适配当前 checkout 语法。
  - **Windows 存储 ACL**：ACL 启动有界化，大型快照审计隔离执行（修复 Windows 启动整树重写 DACL 的路径之一）；privacy-acl 收敛判据换 ACE 指纹（#450 桌面端对齐）——显式 ACE 指纹集合（排序）替代 SDDL 字符串比较，避免 `D:PAI(...)` 与 `D:P(...)` 控制位永不对齐导致每次启动重写 DACL。
- **执行反馈与证据（运行时）**：
  - **环境恢复反馈修正**：exit 127/126/9009 不再被直接定性为「环境/依赖缺失，修复环境后重试」——这是分类线索不是根因结论；exit 126（不可执行）与 127（未找到）分别给出核对方向，完整错误原文保留进上下文供判读，不再灌「这属环境问题非代码缺陷」的误导性结论。
  - **后台任务等待指引修正**：`job await` 提示不再默认带 `pattern="Ready|..."`——启动或输出命中不代表执行完成或测试通过，仅服务就绪探测才按实际日志设置 pattern；测试须核对退出状态与结果。
  - **工具描述口径修正**：bash 描述明确「退出码属于外层进程，复合命令的最终退出码不证明每个子命令成功」。
  - **交付与测试证据移出服务线程**：deliver-task 的验证执行证据收集、提交分类走异步通道，不再阻塞服务线程。
  - **验证计划可操作化**（#514 三连）：工作区测试执行计划统一化；逐项目 runner 完成证据有界收集；剩余验证计划以可执行形式返回而非笼统「未验证」。分片 runner 输出保留、项目证明隔离。
- **会话与上下文**：
  - **已发布渲染钉盘与显式续跑恢复**（issue #500 后续）：已发布的渲染结果钉住不被后续轮次改写；快照不连续的会话提供显式「继续」恢复动作。
  - **通用模型预算恢复统一**（PR #511 收编）：手动与硬限压缩均按配置的模型窗口界定，摘要请求受模型窗口、输出预留与传输预览三重约束，保留受保护历史与事务性持久化。
  - **用户级常驻指令**（PR #509 收编）：`CLAUDE.md` / `AGENTS.md` 形态的项目常驻指令进入完整安全生命周期——加载、继承到子 agent、快照留痕，205 行集成测试覆盖。
- **桌面端**：
  - **侧边栏余额卡片新增今日 Token 消耗**（M 单位，与个人中心同口径）：窗口只取 1 天、按 cache-log mtime 预筛，数值与个人中心今日活动逐字节一致。
  - **GLM pro/资源包账户额度查询修复**（issue #516）：`CREDIT_LIMIT` 计费类型进入解析白名单，pro 账户不再恒报「平台未返回有效额度」。
  - **审批对账收窄**：干预快照补票只在「进入 live」时发生，流状态每次转折不再空转打接口；超时不再把 WebKit 内部文案（"Fetch is aborted"）甩给用户。
  - **重连与确认重启分离**：运行时恢复横幅的「重连」与「确认服务重启」是两个动作，误触重启不再可能。
  - **会话流有界 + 审批对账加栅栏**。
  - **账户资料保存重试**：瞬时失败自动重试，持续失败给出明确原因。
  - **技能快照压缩不删历史**；置顶资源去重并按需物化（issue #512）。
- **模型与渠道**：
  - **Mimo 切换 V2.6 Pro**：V2.5 于 2026-10-21 10:00（Asia/Shanghai）退役，mimo / mimo-api 默认模型与 mimo / mimo-pro / mimo-ultra 短名全部指向 V2.6 Pro。
  - 收编 PR #511 恢复与 Windows 测试设施：压缩 fixture 按真实 prompt 占用校准、异步 teardown 排空、公开树无 Pro 模块可测；Windows 临时路径规范化 + 测试专用 Win32 Job Object 启动器进公开 CI（生产进程终止行为不变）。
- **社区**：微信/QQ 社区群二维码更新。

## 升级注意

- 从 3.33.x 直接自动更新即可，无需迁移。
- 使用 GLM pro/资源包账户的用户：升级后额度面板即可正常显示（此前恒报 invalid-response）。
- 使用 Mimo Token Plan 的用户：V2.5 退役后自动切换 V2.6 Pro，无需操作。
- 生图/探测端点如需访问本机或局域网地址（如本地模型服务），须在设置中显式授权对应 origin。

## 发布节奏

- 候选 catalog 只纳入通过真机验收的平台（沿用 3.32.1 以来的纪律）；darwin-x86_64 与 linux-aarch64 安装包随 Release 页手动下载，不参与自动更新灰度。
