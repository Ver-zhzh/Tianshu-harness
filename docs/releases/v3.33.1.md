# v3.33.1 — Windows 安装包运行时架构修正（热修）

> 日期：2026-10-17
> 上一版本：v3.33.0

## 本版说明

v3.33.0 的 Windows 安装包因**打包机并发构建竞争**装错了运行时：Mac 与 Windows 两条构建腿共用同一资源目录，Windows 包里收进了 macOS（darwin-arm64）的 Node 运行时与原生件，导致 Windows 端启动即 `spawn-failed: program not found`。

本版只修正打包产出，产品代码与 v3.33.0 完全一致（安全收编、会话续跑、驾驶舱重构等内容见 [v3.33.0 说明](v3.33.0.md)）。构建脚本已加并发互斥锁，杜绝同类竞争。

## 升级注意

- **Windows 用户**：v3.33.0 无法启动，请直接装 v3.33.1（或回退 3.32.1）。
- macOS / Linux 用户：v3.33.0 无此问题；本版可选更新。
