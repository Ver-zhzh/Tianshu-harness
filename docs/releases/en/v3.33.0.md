# v3.33.0 — Security intake and session-continuation fixes

> Date: 2026-10-17
> Previous: v3.32.1 (stable channel)

## About this release

This release is primarily a **security intake**: it merges an external security audit (SEC-2026-1016-P0) and a batch of community security PRs, plus a set of session-continuation fixes. All users should upgrade.

## Content

- **Security (important)**:
  - Fixed a P0 bypass where the bash denylist gate and the process self-preservation guard were completely defeated by shell syntax wrapping — subshells `(…)`, brace groups `{…}`, `eval`, `bash -c`, escapes, quoted binaries and quoted env-assignment prefixes all slipped through. In YOLO mode the denylist is the only boundary. All 11 audit PoC vectors are now blocked.
  - Fixed a P1 credential-resolution hijack: for pooled providers, account/balance queries no longer let a stray host-level `<PROVIDER>_API_KEY` env var override the explicitly configured pool key.
  - Community security PR batch (#485/#488–#498): checkout destructive-gate forms, terminal control-character stripping, hardlink escape guards, archive attachment path policy, web-search link rendering hijack fix, and more.
- **Session continuation**:
  - Continuing after an interrupt no longer deadlocks on the prefix guard; interrupt markers no longer rewrite already-sent message bytes.
  - The resume evidence gate gains an explicit "continue with current config" path: sessions with legacy/corrupt snapshots can continue in place after user confirmation (one full cache rebuild); CLI escape: `RIVET_ALLOW_COLD_START=1`.
  - Fixed Codex-channel requests rejected with 400 after image turns (issue #504).
- **Desktop**:
  - Cockpit redesigned on the dark-cockpit principle: annunciator panel (silent when healthy), primary flight display (context load / cache hit rate / delivery / cost) and a trace timeline.
  - Fixed cockpit/Insights collapsing into vertical one-character columns, plan documents leaking machine-readable JSON in preview, and the bare "cockpit" header label.
- **Runtime**: legitimate tool-catalog updates work again after resume (issue #500); late LSP registration gate; output-reserve cap for unknown endpoints (issue #372); convergence emit-gate escalation typing fix (#502).

## Upgrade notes

- From 3.32.x: just take the auto-update; no migration needed.
- Sessions previously blocked by the evidence gate: after upgrading, click "Continue with current config" on the error card to resume in place.
