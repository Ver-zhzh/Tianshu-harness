# v3.37.1 — 桌面更新落盘核对修复与 Android 协议兼容

> 日期：2026-10-29
> 上一版本：v3.37.0

## 本版说明

本版是一次**补丁发布**，主要修复 v3.37.0 发版实测中发现的桌面更新落盘核对问题，并补齐 Android 客户端校验所需的协议声明。v3.37.0 的提交、验证、审查分离与默认工具面行为不变。

## 内容清单

- **桌面更新落盘核对修复**：
  - 用户明确选择「仍然更新」后，路由的 30 秒落盘核对 deadline 在 flush 阶段超时不再继续阻断更新重启；该场景与既有写链失败一样降级为尽力而为。
  - 显式取消始终拦截，未选择「仍然更新」的默认路径继续保持 fail-closed，不会带着未核对的缓冲重启。
  - `UPDATE_SAVE_FAILED` 响应与更新面板现在透出真实 `cause`，便于区分 deadline 超时、写链失败等具体原因，不再只显示统一的「落盘核对失败」。
  - 新增 deadline 三态回归覆盖：默认拒绝、`allowUnsaved` 放行、显式取消仍拒绝。

- **会话收尾与 stall 观测修复**：
  - 修复 Git freshness probe 在 timeout、abort、spawn error 或 exit 后迟迟收不到 `close` 时 Promise 永久 pending 的问题。此前 final `turn_complete` 已发出，run 却永远无法 settlement，observer 每 300 秒重复报告无进展，手动中断与新输入也无法继续。
  - 子进程终止改为有界 TERM→KILL 升级与最终 settle；正常 `close` 仍等待完整 stdout，取消后不再触发 HEAD~N fallback 探针。
  - 新增健康 final、post-final abort、queue continuation 与 mid-run abort 回归；真实 AgentLoop 复现中，单次 abort 后有界释放，observer 进入 idle，后续 run 正常 completed。

- **Android 协议兼容声明**：
  - `/health` 增加 `dataFormatVersion`，运行时能力表增加 `mobileFeatures`，声明会话、聊天、事件、审批、供应商等移动端功能面。
  - 新增 `scripts/export-mobile-contract.ts`，导出包含内核版本、源码修订、协议版本、数据格式版本、能力表与事件集合的机读契约，供 Android 候选版本校验；导出过程不启动运行时、不读取凭据。

- **文档与社区信息**：README 四语更新桌面截图、社区入口与徽章，功能与体量说明对齐 v3.37 实况。

## 升级注意

- 从 v3.37.0 升级无需迁移，既有会话与配置保持不变。
- **3.36.x 桌面客户端仍建议手动下载 DMG/setup 覆盖安装**：旧版自身的应用内升级链缺陷无法由新版安装包事后修复；本地会话数据不受影响。
- macOS 包仍未公证；如首次打开被 Gatekeeper 拦截，安装后执行 `xattr -cr /Applications/Tianshu.app`。
