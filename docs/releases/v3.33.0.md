# v3.33.0 — 安全收编与会话续跑修复

> 日期：2026-10-17
> 上一版本：v3.32.1（稳定通道）

## 本版说明

本版以**安全修复**为主轴：收编外部安全审计（SEC-2026-1016-P0）与社区安全 PR 批次，并修复一组会话续跑链路问题。建议所有用户尽快升级。

## 内容清单

- **安全（重要）**：
  - 修复 Bash 黑名单门禁与进程自我保护被 shell 语法包装完全穿透的 P0 漏洞——子壳 `(…)`、brace 组 `{…}`、`eval`、`bash -c`、转义与引号包装、带引号环境赋值前缀此前全部绕过门禁；YOLO 模式下黑名单是唯一边界。外部审计 PoC 11 组载荷现 100% 拦截。
  - 修复多 key 池凭据解析被宿主全局环境变量劫持（P1）：池化 provider 的账户/余额查询不再被 `<PROVIDER>_API_KEY` 环境变量顶掉显式配置的池主 key。
  - 收编社区安全 PR 批次（#485/#488–#498）：checkout 清场强制形态收口、终端控制符剥离、硬链接越界读取门禁、压缩包附件路径策略、网页搜索链接渲染劫持修复等。
- **会话续跑**：
  - 打断（abort）后继续对话不再被前缀守卫误拒死锁；打断标记不再改写已发送的消息字节。
  - resume 证据门新增「以当前配置继续」显式通道：旧版/损坏快照的会话可经用户确认后原地续跑（缓存全量重建一次），CLI 可用 `RIVET_ALLOW_COLD_START=1`。
  - 修复 Codex 通道带图轮次后请求被 400 拒绝（issue #504）。
- **桌面端**：
  - 驾驶舱暗舱重构：告警灯板（全正常时静默）+ 主仪表区（上下文水位/缓存命中率/交付状态/成本）+ 轨迹时间轴。
  - 修复驾驶舱/Insights 界面塌缩成逐字竖排、计划文档预览泄漏机读 JSON、顶栏驾驶舱名称裸显。
- **运行时**：工具表 resume 后合法更新恢复生效（issue #500）；LSP 晚到注册闸门；未知端点的输出预留封顶（issue #372）；发射门升级分型修复（#502）。

## 升级注意

- 从 3.32.x 直接自动更新即可，无需迁移。
- 曾被「禁止静默冷启动」拦住的旧会话：升级后在报错卡片点「以当前配置继续」即可原地续跑。
